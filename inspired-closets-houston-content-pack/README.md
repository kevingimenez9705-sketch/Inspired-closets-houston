# Paquete de contenidos — Inspired Closets Houston

Material organizado para el equipo que está diseñando una presentación web sobre los servicios de Inspired Closets Houston.

## Contenido del paquete

- `content/brief-presentacion-es.md`: síntesis editorial y propuesta de estructura para la presentación.
- `content/equipo.md`: integrantes del equipo y cargos.
- `content/fuentes-y-contacto.md`: URLs fuente, contacto, ubicación y fechas de referencia.
- `manifests/asset-map.csv`: relación verificable entre cada imagen, su sección y el contenido asociado.
- `manifests/notas-de-calidad.md`: limitaciones, alertas editoriales y recomendaciones de uso.
- `images/`: 36 imágenes originales agrupadas por función, servicio, proceso y equipo.

## Cómo utilizarlo

1. Abrir `manifests/asset-map.csv` en Excel, Google Sheets o Numbers.
2. Filtrar por `category` o `service` para encontrar los recursos correspondientes a cada diapositiva.
3. Usar `associated_content` para mantener la relación correcta entre imagen y mensaje.
4. Consultar `content/brief-presentacion-es.md` para construir el relato de la presentación.
5. Revisar `manifests/notas-de-calidad.md` antes de publicar precios, plazos o contenido marcado para validación.

## Criterio de asociación

Las asociaciones se basan en la estructura semántica recuperada de las páginas: posición en la sección, texto alternativo, título inmediatamente relacionado y URL de origen. Las asociaciones directas se marcan con confianza `alta`.

## Uso de los recursos

Las imágenes y textos fuente pertenecen a Inspired Closets y/o sus titulares. Este paquete está preparado para trabajo interno de diseño. Antes de publicar o distribuir externamente la presentación, el equipo debe confirmar que cuenta con los permisos de uso correspondientes.
